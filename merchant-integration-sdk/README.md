# Merchant Integration SDK

Client-side JavaScript SDK embedded in merchant storefronts for rendering Affirm payment messaging, checkout buttons, and orchestrating secure communication with Affirm's web app. Optimized for bundle size, Web Vitals, and backward compatibility.

**Stack**: TypeScript, Webpack, PostMessage API

**Build**: `npm install && npm run build` • **Test**: `npm run test` • **Dev**: `npm run dev`
